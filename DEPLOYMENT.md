# Yayına alma kontrol listesi

- GitHub'da public repository oluşturun ve proje kökünü push edin.
- Vercel veya Netlify'da repository'yi içe aktarın.
- Build command: `npm run build`
- Output directory: `dist`
- SPA fallback için `vercel.json` veya Netlify `_redirects` ekleyin.
- Canlı URL'yi teslim formuna yazın.

Not: API örneği ayrı Node servisi gerektirir. Arayüz LocalStorage ile çalıştığından frontend deploy'u için API zorunlu değildir.
